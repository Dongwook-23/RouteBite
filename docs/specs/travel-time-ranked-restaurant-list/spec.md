# 위치 입력 → 이동시간순 맛집 리스트

## User-visible outcome

사용자가 도시나 장소를 텍스트로 검색해서 하나를 선택하고 이동수단(도보/자동차)을 고르면, 그 위치 주변 음식점들이 실제 이동시간 기준으로 가까운 곳부터 먼 곳까지 정렬된 리스트로 나타난다. 사용자는 각 음식점까지 거리를 더 이상 직접 검색하지 않아도 된다.

## Scope

- 위치 입력: 자유 텍스트(주소/장소명) 검색 후 자동완성 목록에서 하나를 선택 → 좌표로 변환.
- 이동수단 선택: 도보 또는 자동차 중 선택 (대중교통, 자전거 등은 이번 범위 밖).
- 선택한 위치 주변의 음식점 목록을 가져온다.
- 선택한 이동수단 기준으로 각 음식점까지의 실제 이동시간을 계산한다.
- 결과를 이동시간이 짧은 순(가까운 순)으로 정렬해 리스트로 보여준다.

## Out of scope (off-limits)

- 평점/리뷰 기반 필터링이나 정렬 — [restaurant-data-source](../../decisions/restaurant-data-source.md) 결정에 따라 이번 범위에서는 카테고리 기반 리스트만 제공한다.
- 대중교통 이동수단 — 도시별 데이터 품질 편차 때문에 이번 범위에서 제외.
- 여러 도시를 한 여행에 포함하는 것 — PRODUCT.md 경계상 한 번에 한 도시만 다룬다.
- 리스트에서 여러 곳을 선택해 방문 순서(경로)를 추천하는 기능 — 이 스프린트에는 포함하지 않는다.
- 여행 일수 입력이나 날짜별(하루 최대 4곳) 자동 배분 — 다음 범위에서 다룬다.
- 검색 결과를 저장하거나 계정에 담는 기능.

## Acceptance criteria

- 사용자가 장소명이나 주소 일부를 입력하면 자동완성 후보가 나타나고, 하나를 선택하면 그 위치가 기준점으로 확정된다.
- 존재하지 않거나 모호한 텍스트를 입력하면 유효한 후보가 없다는 것을 사용자가 알 수 있다.
- 사용자는 도보 또는 자동차 중 이동수단을 하나 선택할 수 있다.
- 기준점 선택과 이동수단 선택이 끝나면, 주변 음식점 목록이 화면에 나타나며 각 항목에 이름, 주소, 기준점으로부터의 이동시간(및 거리)이 표시된다.
- 목록은 이동시간이 짧은 것부터 긴 순서로 정렬되어 있다.
- 기준점 주변에서 음식점을 찾지 못한 경우, 목록이 비어 있다는 것을 사용자가 알 수 있다 (빈 화면으로 남지 않는다).
- 실제 서비스 지역(예: 서로 다른 대륙의 도시 두 곳 이상)에서 동작을 실행해 이동시간 값이 실제로 그럴듯한 범위인지 확인할 수 있다.

## Settled constraints and rationale

- 맛집 데이터 소스와 이동시간 계산 방식은 [restaurant-data-source](../../decisions/restaurant-data-source.md)를 따른다 (Geoapify Places API 카테고리 기반 목록 + Geoapify Routing/Route Matrix API 이동시간).
- 위치 입력은 자유 텍스트 검색 후 자동완성으로 확정한다 — 지도 클릭 UI보다 구현이 가볍고, 전 세계 도시를 텍스트 검색으로 바로 다룰 수 있어 이번 범위에 적합하다고 사용자가 확인함.
- 이동수단은 도보·자동차만 지원한다 — 대중교통은 Geoapify에서도 근사치이고 도시별 데이터 품질 편차가 커서, 이번 범위의 검증 대상에서 제외하기로 사용자가 확인함.

## Assumptions

- 주변 음식점 검색 반경은 기준점으로부터 약 3km로 둔다 (도보로도 현실적으로 갈 수 있는 범위 고려). 결과가 너무 적거나 많으면 이후 조정 가능한 값으로 취급한다.
- 한 번에 보여주는 음식점 수는 최대 20곳으로 둔다.
- Geoapify 카테고리 중 음식점에 해당하는 카테고리(예: catering.restaurant 및 하위 카테고리)를 폭넓게 포함하고, 세부 업종 필터는 두지 않는다.

## Deferred points

- 평점/리뷰 데이터를 어떤 외부 소스로 보강할지, 그리고 그것을 정렬/필터에 어떻게 반영할지.
- 대중교통 모드 지원 여부와 시점.
- 가격대, 음식 종류 등 추가 필터 제공 여부.

## Remaining risks

- Geoapify 무료 티어의 호출 한도에 따라, 자동완성·장소 검색·이동시간 계산을 함께 쓸 때 요청 수가 예상보다 빨리 소진될 수 있다.
- 도시에 따라 Geoapify Places 데이터의 음식점 커버리지가 고르지 않을 수 있어, 일부 도시에서는 목록이 빈약하게 나올 수 있다.
