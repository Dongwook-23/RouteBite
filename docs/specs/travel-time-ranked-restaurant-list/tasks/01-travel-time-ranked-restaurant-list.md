# 01 — 위치 입력 → 이동시간순 맛집 리스트

## Outcome

사용자가 장소를 텍스트로 검색해 자동완성으로 하나를 선택하고 도보 또는 자동차 중 이동수단을 고르면, 그 위치 주변 음식점 목록이 실제 이동시간이 짧은 순서로 정렬되어 화면에 나타난다.

## Blockers

None.

## Acceptance criteria

- [x] 장소명이나 주소 일부를 입력하면 자동완성 후보가 나타나고, 하나를 선택하면 그 위치가 기준점으로 확정된다.
- [x] 존재하지 않거나 모호한 텍스트를 입력하면 유효한 후보가 없다는 것을 사용자가 알 수 있다.
- [x] 사용자는 도보 또는 자동차 중 이동수단을 하나 선택할 수 있다.
- [x] 기준점과 이동수단 선택이 끝나면 주변 음식점 목록이 나타나며, 각 항목에 이름·주소·기준점으로부터의 이동시간(및 거리)이 표시된다.
- [x] 목록은 이동시간이 짧은 것부터 긴 순서로 정렬되어 있다.
- [x] 기준점 주변에서 음식점을 찾지 못하면, 목록이 비어 있다는 것을 사용자가 알 수 있다 (빈 화면으로 남지 않는다).

## Constraints

None.

## Verification

- 서로 다른 대륙의 도시 두 곳 이상(예: 서울, 파리)에서 실제로 검색부터 결과 표시까지 수행해, 이동시간 값이 그럴듯한 범위인지 눈으로 확인한다.
- 결과가 없을 법한 위치(예: 도심에서 멀리 떨어진 외곽)로 실제 검색해 빈 상태 처리를 확인한다.
- 모호하거나 존재하지 않는 텍스트를 입력해 자동완성 후보가 없을 때의 처리를 확인한다.
- `npm run typecheck`, `npm run lint`, `npm run test`가 통과한다.
