# 01 — 음식 종류 필터

## Outcome

이동시간순 음식점 목록에서, 실제로 목록에 있는 음식 종류들 중 하나를 골라 그 종류의 음식점만 볼 수 있다. 필터를 바꾸거나 초기화해도 이미 선택(체크)해둔 곳은 그대로 유지된다.

## Blockers

None. (선행 스펙 [multi-day-trip-planning](../../multi-day-trip-planning/spec.md)의 태스크 01이 이미 completed 상태이며, 이 태스크는 그 화면 위에 이어서 구현한다.)

## Acceptance criteria

- [x] 음식점 목록이 나타나면, 그 목록에 실제로 있는 음식 종류들이 필터 선택지로 나타난다.
- [x] 목록에 없는 음식 종류는 필터 선택지에 나타나지 않는다.
- [x] 음식 종류 하나를 선택하면, 그 종류에 해당하는 음식점만 보인다.
- [x] "전체"를 선택하면 다시 모든 음식점이 보인다.
- [x] 필터를 적용한 상태에서도, 필터에 가려진 음식점을 포함해 이미 선택(체크)해둔 곳의 선택 상태와 날짜별 배분 결과는 그대로 유지된다.
- [x] 새로운 위치를 검색하거나 이동수단을 바꿔 음식점 목록이 다시 불러와지면, 필터는 "전체" 상태로 돌아간다.

## Constraints

None.

## Verification

- 서로 다른 대륙의 도시(예: 서울, 파리)에서 실제로 필터 선택지가 목록의 음식 종류와 일치하는지, 필터 적용 결과가 그럴듯한지 확인한다.
- 필터를 적용한 상태에서 다른 곳을 추가로 선택/해제해도 선택 상태와 날짜별 배분이 유지되는지 확인한다.
- 새 위치 검색이나 이동수단 변경 후 필터가 "전체"로 초기화되는지 확인한다.
- `npm run typecheck`, `npm run lint`, `npm run test`가 통과한다.

## Execution
